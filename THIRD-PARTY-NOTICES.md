## Microsoft .NET and System.Text.Json

The Revit 2025 plugin references
[System.Text.Json 8.0.6](https://www.nuget.org/packages/System.Text.Json/8.0.6).
For the `net8.0-windows` release, `System.Text.Json` is supplied by the .NET 8
shared framework loaded by Revit; the plugin ZIP does **not** redistribute a
separate `System.Text.Json.dll`.

`RevitMCPUpdater.exe` is published as a framework-dependent single-file
application. It contains the standard .NET apphost generated by the SDK, but
does **not** bundle the .NET runtime or shared-framework DLLs. A compatible
.NET 8 runtime is supplied by the Revit 2025 installation.

Official System.Text.Json source:
[dotnet/runtime at the 8.0.6 package source commit](https://github.com/dotnet/runtime/tree/ef853a71052646a42abf17e888ec6d9a69614ad9/src/libraries/System.Text.Json)

Official .NET Runtime source:
[dotnet/runtime](https://github.com/dotnet/runtime)

[.NET Runtime MIT License](https://github.com/dotnet/runtime/blob/ef853a71052646a42abf17e888ec6d9a69614ad9/LICENSE.TXT)

## Build-time and host API references not redistributed

The release packaging and validation scripts explicitly exclude Autodesk host
API assemblies:

- `RevitAPI.dll` and `RevitAPIUI.dll` are supplied by an installed, licensed
  copy of Autodesk Revit. The Nice3point Revit API NuGet packages are
  compile-time CI references only.
- `acmgd.dll`, `acdbmgd.dll`, and `accoremgd.dll` are supplied by an installed,
  licensed copy of Autodesk AutoCAD. The `AutoCAD.NET` NuGet package is a
  compile-time CI reference only.
- MinVer and compiler/analyzer tooling used during builds are not included in
  either release ZIP.

No Autodesk Revit or AutoCAD binaries are redistributed by these release
archives.
